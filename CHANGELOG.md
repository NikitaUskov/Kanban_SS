# История изменений

## 1.2.0 — 2026-07-30

### Совместная работа с карточкой

- добавлен один основной ответственный;
- добавлен отдельный признак завершения задачи;
- добавлены комментарии с редактированием и удалением только собственных сообщений;
- добавлены чек-листы: создание, изменение текста, отметка выполнения, изменение порядка и
  удаление;
- изменения ответственного, завершения, комментариев и чек-листа фиксируются в журнале;
- добавлен авторизованный каталог активных пользователей.

### Интерфейс

- существующая карточка открывается в боковой панели без ухода с доски;
- на телефоне панель занимает весь экран;
- карточки на доске показывают только полезные индикаторы: срок, приоритет, комментарии,
  прогресс чек-листа и инициалы ответственного;
- завершённые карточки визуально приглушены;
- колонки можно сворачивать; состояние хранится персонально в `localStorage`;
- расширены фильтры по ответственному, выполнению, собственным задачам, комментариям и
  чек-листам;
- фильтры остаются закрытыми по умолчанию.

### Backend и база

- добавлена миграция `20260730_0002_collaboration.py`;
- в `cards` добавлены `assignee_user_id` и `completed_at`;
- добавлены таблицы `card_comments` и `card_checklist_items`;
- readiness-проверка контролирует наличие новых таблиц и revision `20260730_0002`;
- snapshot доски возвращает ответственного и агрегаты комментариев/чек-листа;
- добавлены интеграционные тесты совместной работы.

### Проверки

- 23 backend-тест;
- 16 frontend-тестов;
- Alembic upgrade и model/migration parity;
- проверка синтаксиса JavaScript и адаптивной структуры интерфейса.

## 1.1.0 — 2026-07-28

### Развёртывание

- добавлен `setup-server.ps1`;
- добавлен `start-kanban-server.ps1` с временным IPv4 mapping для регистрации Quick Tunnel;
- добавлены ожидание DNS, исключение `api.trycloudflare.com`, IPv4 edge и HTTP/2;
- Git push выполняется через HTTPS с повторными попытками;
- устаревшие PID-файлы больше не блокируют запуск и не приводят к остановке чужих процессов;
- автозапуск использует повышенные права и новый серверный launcher;
- добавлены `status-kanban.ps1` и `update-from-main.ps1`.

### Backend

- исправлен разбор `ALLOWED_ORIGINS` в Pydantic Settings;
- CORS-origin GitHub Pages нормализуется в нижний регистр;
- модель `users.username` приведена в соответствие с initial migration;
- исправлены Ruff warnings и форматирование.

### Frontend

- исправлен вызов native `fetch`;
- фильтры вынесены в сворачиваемую боковую панель;
- из карточек списка досок удалены служебные счётчики;
- улучшена адаптивная типографика и компоновка.
