# Архитектура Kanban Board 1.3.0

## Компоненты

```text
Browser
  └─ GitHub Pages: HTML/CSS/ES modules
       └─ runtime-config.json → текущий Quick Tunnel URL
            └─ Cloudflare Quick Tunnel
                 └─ FastAPI/Uvicorn on Windows
                      └─ SQLAlchemy + SQLite
                           └─ Alembic revision 20260806_0003
```

## Данные

Основные таблицы:

- `users`, `refresh_tokens`;
- `boards`, `board_members`, `columns`, `cards`;
- `card_comments`, `card_checklist_items`;
- `user_invitations`, `password_reset_tokens`;
- `notifications`, `activity_log`.

`cards.parent_card_id` реализует один уровень подзадач. Сервис запрещает создание подзадачи у подзадачи.

## Доступ

Сначала проверяется системная роль, затем членство на доске. `owner` и `admin` имеют административный системный доступ, но членство используется для отображения и контекста доски. Редактирование карточек требует минимум `editor`; управление доской и участниками — `admin`.

## Приглашения

Генерируется криптографический токен. Пользователю отправляется полный URL, в SQLite хранится SHA-256 хеш. Одно приглашение может быть принято один раз, имеет срок действия и может быть отозвано.

## Email

SMTP является необязательным адаптером. Ошибка SMTP не отменяет создание приглашения: администратор получает ручную ссылку и статус ошибки. Это предотвращает зависимость основного Kanban от внешней почты.

## Согласованность SQLite

Записи координируются приложением. Миграции SQLite используют Alembic batch mode. На время перестройки таблиц внешние ключи отключаются на raw DBAPI connection, затем выполняется `PRAGMA foreign_key_check`; при нарушении migration завершается ошибкой.

## Безопасность

- Argon2id для паролей;
- короткоживущий access token и refresh token с отзывом;
- rate limiting входа;
- CORS только для GitHub Pages и локальной разработки;
- секреты только в `.env`;
- токены приглашений/сброса хешируются;
- одинаковый ответ при запросе восстановления пароля;
- последний владелец защищён;
- оптимистические версии карточек, комментариев и чек-листов.
